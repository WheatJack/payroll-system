# 薪酬专员操作手册

> **适用账号**：`hr01`（角色「薪酬专员」）。本手册覆盖月度核算、入职、参保、专项扣除、调薪/离职/调动、个税核对。
> 所有按钮名称与界面一致；当前版本做不到的事会明确标注，请勿按旧经验硬套。

---

## 0. 一页速查：你能做什么 / 不能做什么

| ✅ 你能做 | ❌ 你不能做（当前版本） |
|---|---|
| 新建工资期间、生成基础数据 | 锁定/解锁期间（复核员的职责） |
| 查看生成时被跳过的人员和原因 | 关闭结果弹窗后回看跳过名单（无入口） |
| 导入绩效/加班/奖金/扣款（变动项） | 用导入新增员工或新建工资记录 |
| 在编制台修改变动项金额 | 在编制台改基本工资、津贴、工龄、社保、公积金、个税 |
| 新建/批量导入员工、配薪酬、调薪、离职、调动 | 批量调薪（普调）、月中调薪按天拆分、离职结算 |
| 录入参保信息、专项附加扣除 | 员工自助查工资条、工资条签收 |
| 看月/年报、个税核对，锁定后导出 | 银行代发文件、人员花名册导出 |

**三条红线**：锁定后不能改；手工改过的值重算不会丢；导入有失败行、生成有失败人，都不能提交/锁定。

## 1. 登录与界面

1. 浏览器打开管理员提供的系统地址，输入用户名、密码 →「登 录」。
2. 默认落在「**工资期间**」（你每天的主入口）。
3. 左侧菜单：人员管理 / 工资项 / 工资期间 / 月度报表 / 年度报表 / 个税核对。右上角灰色标签是你的数据范围代码（`ALL` = 集团全部主体）。
4. 「工资期间」列表每 15 秒自动刷新一次（别人锁定后你能看到状态变化）；**编制台不自动刷新**（避免冲掉未保存的修改）。

## 2. 月度核算 SOP（按顺序做）

### 2.0 一张图看懂一个月

| 顺序 | 做什么 | 在哪里 | 做完的标志 |
|---|---|---|---|
| 1 | 建本月期间 | 工资期间 → 新建期间 | 出现本月，状态「草稿」 |
| 2 | 生成基础数据 | 期间行 → 生成 | 状态「编制中」，成功 N 人 |
| 3 | 查跳过名单 | 生成结果弹窗 | 知道谁没算、为什么 |
| 4 | 导入绩效等变动项 | 期间行 → 导入 | 批次已提交，失败 0 行 |
| 5 | 编制台改数、核对合计 | 期间行 → 编制台 | "无未保存修改"，合计对得上 |
| 6 | 交复核员锁定 | 线下通知 | 状态「已锁定」，编制台只读 |
| 7 | 出报表、导出 | 编制台 / 报表页 | 文件下载成功 |

### 2.1 建期间

1. 「工资期间」→ 右上「**新建期间**」→ 选「工资年月」（例如 2026-11）→「**创建**」。
2. 出现「**期间 2026-11 已就绪（草稿）**」即成功。同主体同月只会有一条，重复创建返回已有期间；年月框默认空，要自己选。

### 2.2 生成基础数据

1. 期间行点「**生成**」（**没有二次确认**，点一下即全量重算）。
2. 在「生成基础数据」窗口看：**批次状态**（`SUCCESS` 才算成功）、**应生成/成功/失败**、黄色警示条。
3. 生成后状态变「编制中」，并记录"编制人"（编制人不能给自己这期锁定）。

注意：已有记录会被重算，但**手工改过的值和导入的值会保留**；进度条可能停在 100% 以下（被跳过的人不计入完成数），以状态和人数为准，别因进度条没满就重复点。

### 2.3 查跳过名单：谁没算、为什么

生成结果弹窗里「**跳过人员（不产生 0 元记录）**」有两列：工号、跳过原因。

| 常见原因 | 处理 |
|---|---|
| 未配置薪酬档案 | 人员管理 → 搜工号 →「薪酬档案」→「配置薪酬」→ 保存 → 重新生成 |
| 离职状态未填离职日期，已跳过 | 编辑人员，补离职日期并确认状态 → 重新生成 |
| 当月后才入职 / 当月前已离职 | 本来就不该发，不用处理 |

⚠️ 跳过名单**只在弹窗里，关掉就看不到了**，期间列表没有回看入口；关闭前请截图留档，要再核对只能重新生成。

「**失败明细**」是另一回事：跳过=按规则不该算（正常）；失败=该算算错了（异常）。**失败人数 > 0 时这一期不能锁定**，必须处理后重新生成。

### 2.4 导入绩效（变动项）

> 界面「变动项」= 绩效奖金、加班工资、其他奖金、考勤扣款、其他扣款。导入绩效选「变动项」。

入口：工资期间 → 该期间行「**导入**」（只有「编制中」才有此按钮）。

1. **下载模板**：选「变动项」→「**下载模板 xlsx**」。模板有两行表头（第 1 行中文、第 2 行系统字段码），**从第 3 行填数据**；第 2 行不要删改。不需要的列留空即可。
2. **上传预校验**：拖入 xlsx → 选导入模式（「**有则覆盖**」默认 / 「**有则跳过**」）→「**开始预校验**」。预校验不写库。
3. **看结果并提交**：表格逐行给出 行号/列/原值/错误码/原因；有失败点「**下载错误报告**」，改完重传。**失败行不清零，「确认提交」是灰的**，后端也会拒绝。失败 0 行 →「**确认提交**」→ 提示「提交成功：N 行」。
4. 回编制台点「刷新」才能看到新金额。

常见错误：

| 提示 | 原因 | 处理 |
|---|---|---|
| `NO_RECORD` 该工号在本期间没有核算记录 | 本期没生成/被跳过；导入只改已有记录 | 先解决生成问题 |
| `NAME_MISMATCH` 工号 X 对应「张三」，与文件中的「李四」不符 | 工号或姓名写错 | 核对工号（系统会拦，防止改错人的钱） |
| `AMOUNT_INVALID` 金额格式不正确 | 填了文本、货币符号、千分位 | 只填数字，最多两位小数 |
| `AMOUNT_NEGATIVE` 金额不能为负数 | 扣款填了负数 | 扣款填到"考勤扣款/其他扣款"列，填正数 |
| `AMOUNT_OUT_OF_RANGE` 单项上限 1,000,000.00 | 金额异常大 | 核对是否多打了 0 |
| `DUPLICATE_IN_FILE` 文件内工号重复 | 同一人两行 | 删重复行 |
| 该文件已提交或正在处理 | 同一文件重复上传 | 换文件，或先查批次记录 |

### 2.5 编制台改数（筛选、编辑、保存）

入口：工资期间 → 期间行「**编制台**」。

**哪些列能改**

- **能改（双击编辑）**：绩效奖金、加班工资、其他奖金、考勤扣款、其他扣款等变动项（列由工资项字典决定）。
- **只读**：基本工资、岗位津贴（来自薪酬档案）；工龄工资、社保个人、公积金个人、个人所得税（系统计算）。
- 所以：**编制台不能单独调某人某一期的基本工资**，要改只能改薪酬档案后重新生成（会按生效日期影响后续所有期间）。

**筛选与编辑**

- 顶部按部门/员工类型/职级筛选，输入「工号/姓名」关键字（稍等自动生效）；「**清除筛选**」恢复全表，「**刷新**」重拉数据（有未保存修改会先确认，确认后修改丢失）。
- 双击单元格输入金额；批量可**单击起点 → Shift+单击终点 → Ctrl/Cmd+V** 粘贴 Excel 多行数据；只读/越界/非法值会跳过并提示。
- 改过的格子变橙色，顶部显示「N 行 / M 个单元格未保存」。

**保存**

1. 点「**保存修改**」→ 提示「已保存 N 行」→ 看到「**无未保存修改**」才算落库。
2. 若提示"有 N 行已被他人修改（已高亮）"：红行是冲突行，修改仍在，**先刷新再重改**。
3. 要全部作废点「放弃修改」；离开页面会被拦一次"未保存的修改，离开将丢失"，这是保护。

### 2.6 核对合计

三个口径必须对得上：

1. **编制台底部横栏**：应发合计 / 扣款合计 / 实发合计（筛选时只统计筛选结果，旁边有 `*`）。
2. **工资期间列表**：人数、应发合计、实发合计。
3. **月度报表**（锁定后才有数）：按部门分行的合计。

实发 = 应发 − 扣款（扣款已含社保个人、公积金个人、个人所得税）。人数是"有工资记录的人数"，不等于在职人数。不一致先点刷新再比。

### 2.7 提交复核、锁定

- **你没有锁定权限**，锁定由「薪酬复核」（`hr02`）执行。
- 你的动作：确认合计 → 线下通知复核员 → 复核员在「工资期间」点「锁定」。
- 锁定后：状态「已锁定」，编制台只读，导入按钮消失，工资表/工资条才可导出。
- 要改已锁定期间，只能请复核员**解锁**（必须填原因、写审计），改完**必须重新锁定**。

### 2.8 出报表、导出

| 要什么 | 去哪里 | 前提 |
|---|---|---|
| 整期工资表 | 编制台 →「导出工资表」 | 期间已锁定 |
| 工资条（按当前筛选） | 编制台 →「导出工资条（N 人）」 | 期间已锁定且列表不空 |
| 月度/年度汇总 | 月度报表 / 年度报表 → 查询 →「导出 xlsx」 | 只统计已锁定月份 |
| 年度个税核对 | 个税核对 → 查询 →「导出 xlsx」 | 只统计已锁定月份 |

**工资条按"当前筛选后可见的行"导出**：筛了某部门就只导该部门，全量导出前先「清除筛选」。列表 0 人时系统会拦住。年度报表「按部门」且你是集团范围时，必须先选法人主体。

### 2.9 月结检查清单

- [ ] 状态「编制中」，最近一次生成 `SUCCESS`
- [ ] 跳过名单已处理并**截图留档**
- [ ] 失败人数 = 0；导入失败行 = 0 且已提交
- [ ] 编制台"无未保存修改"
- [ ] 期间列表的应发/实发 = 编制台合计
- [ ] 已通知复核员锁定


## 3. 入职

### 3.1 单人建档

「人员管理」→「**新增人员**」，共 15 个字段。**必填 6 项**：工号、姓名、员工类型、证件号码、部门、入职日期。保存成功提示「**人员已创建**」。

填写要点：

- **工号**全局唯一；**证件类型**默认就是英文代码 `ID_CARD`，保留即可；**证件号码**只提交一次、加密存储，列表只显示后 4 位。
- **部门**只能选该员工所属主体下的部门，部门树**不支持搜索**。
- **职级**是自由文本（如 `P6`），公司内写法要统一，否则后续统计对不上。
- **参加工作**旁的提示写"用于工龄计算"，但**工龄工资用的是入职日期**，这个字段只影响"社会工龄"展示，别被误导。
- 保存约 1 秒，期间按钮转圈；失败时表单内容不会丢。

### 3.2 配薪酬（不配就不会生成工资）

人员列表 → 行内「**薪酬档案**」→「当前生效薪酬」→「**配置薪酬**」→ 填生效日期（默认**次月 1 日**，可倒填到入职月）、基本工资、固定津贴（「+ 添加津贴」）、调整原因 →「**保存**」→ 提示「薪酬档案已创建，自 YYYY-MM-DD 生效」。没有薪酬档案的人生成时会被跳过。

### 3.3 批量导入（13 列模板）

入口：「人员管理」→ 右上「**批量导入**」。

流程：读「填表说明」→「**下载人员模板 xlsx**」→ 填好拖入 →「**开始预校验**」→ 有失败「**下载错误报告**」改完重传 → 失败 0 行「**确认提交**」→ 二次确认「将导入 N 名员工及其薪酬档案」→「提交」。

| # | 列名 | 必填 | 写法 |
|---|---|---|---|
| 1 | 工号 | 是 | 全局唯一，不能与已有工号重复 |
| 2 | 姓名 | 是 | |
| 3 | 性别 | 否 | `男`/`女`/`未知`（也接受 1/2/0） |
| 4 | 员工类型 | 是 | `REGULAR`正式 / `PROBATION`试用 / `INTERN`实习 / `LABOR`劳务 / `OUTSOURCE`外包 / `REHIRE`返聘 |
| 5 | 证件类型 | 否 | 留空默认 `ID_CARD` |
| 6 | 证件号码 | 是 | 全局唯一，文件内也不能重复 |
| 7 | 手机号 | 否 | |
| 8 | 部门编码 | 是 | **必须是已存在的部门编码**（不是名称） |
| 9 | 职级 | 否 | 自由文本 |
| 10 | 岗位 | 否 | 自由文本 |
| 11 | 入职日期 | 是 | `YYYY-MM-DD` |
| 12 | 参加工作时间 | 否 | `YYYY-MM-DD` |
| 13 | 基本工资 | 是 | 数字，两位小数，不能为负 |

特殊规则：提交会**同时建人员 + 薪酬档案**，档案生效日 = 该行入职日期；批量导入**只建基本工资、不带固定津贴**；有失败行则整份不写入；同一文件重复上传会被拒。

常见错误：模板列不匹配（表头被改，重新下载模板）；`EMP_NO_EXISTS`/`ID_NO_EXISTS`（已存在，改用编辑）；`DEPT_NOT_FOUND`（编码错，去部门管理查）；`DATE_INVALID`（日期格式）；`EMPLOYEE_TYPE_INVALID`（类型写中文）；`GENDER_INVALID`；基本工资格式不正确。


## 4. 参保信息录入

入口：人员管理 → 行内「**薪酬档案**」→ 抽屉「**参保信息**」→「**新增参保信息**」。

1. 选「**参保城市**」：内置北京（BJ）/上海（SH）/深圳（SZ）；选完下方出现「**险种参考**」（险种、个人比例、基数上下限）。提示"该城市编码不存在或未配置险种参数"时提交会被拒，请改选内置城市。
2. 「**缴费基数**」：**留空 = 自动算**（按近 12 期平均应发，无历史时按当月应发，并受城市上下限约束）；要指定就填金额。
3. 「**公积金比例**」：小数，`0.12` = 12%，范围 0～1；**留空按城市参数**。
4. 选生效日期（默认本月 1 日）→「**保存**」。

注意：**没配参保信息的人社保公积金为 0**（页面有黄色提示）；参保信息按生效区间管理，调城市/基数应新增区间，不要改历史；内置比例为参考值，界面不能改比例/上下限，调整找开发。下表上下限为社保口径，公积金下限更低（北京 2,420 / 上海 2,690 / 深圳 2,360）。

| 城市 | 养老 | 医疗 | 失业 | 公积金 | 基数下限～上限 |
|---|---|---|---|---|---|
| 北京 BJ | 8% | 2%（另有 3 元大病） | 0.5% | 12% | 6,821 ～ 35,283 |
| 上海 SH | 8% | 2% | 0.5% | 7% | 7,384 ～ 36,921 |
| 深圳 SZ | 8% | 2% | 0.3% | 5% | 2,360 ～ 38,892 |


## 5. 专项附加扣除录入

同一抽屉 →「**专项附加扣除**」→「**新增专项附加扣除**」：选扣除项目、填月额、生效日期（默认本月 1 日）、结束日期（留空=至今）、备注 → 保存。

| 扣除项目 | 常见额度（月） |
|---|---|
| 子女教育 / 婴幼儿照护 | 2,000 元/子女 |
| 继续教育 | 400 元（学历）或按年 3,600 元（职业资格） |
| 住房贷款利息 | 1,000 元 |
| 住房租金 | 800 / 1,100 / 1,500 元（按城市档） |
| 赡养老人 | 3,000 元（独生）或分摊 |

专项附加扣除按月计入累计减除，直接影响个税；删除会二次确认，但**已锁定期间的税额不会自动重算**（需解锁重算）。**大病医疗不在按月录入范围**（年度汇算处理）。员工不登录系统，这些数据只能 HR 维护。

## 6. 调薪 / 离职 / 调动

### 6.1 调薪

人员管理 → 搜工号 →「**薪酬档案**」→「**调薪**」→ 生效日期（默认**次月 1 日**）、基本工资（带出当前值）、固定津贴、调整原因 → 保存 →「已保存新薪酬区间，自 YYYY-MM-DD 生效」。

- 按"**期间末日生效的档案**"整月计算：12-01 生效的调薪，11 月仍按旧薪，12 月整月按新薪。
- **月中生效不拆分**：生效日填 12-15，12 月仍整月按新标准，前 14 天不折算。
- 调薪不改历史工资表，只有重新生成才按新档案重算。
- 「当前生效薪酬」会把下月才生效的档案也显示出来，**以生效日期为准**。
- 没有审批流、没有普调入口；200 人普调只能逐个做。

### 6.2 离职

人员管理 →「**编辑**」→ 填「**离职日期**」+ 把「**在职状态**」改为「离职」→ 保存。**两个字段都要填**：只填日期不改状态，列表仍显示在职；只改状态不填日期，生成时会被跳过。

当月算法：基本工资按**实际计薪工作日 / 21.75** 折算，固定津贴同比折算；**工龄工资整月照发、不折算**（当前口径）；次月起不再生成。离职没有原因/类型/结算，且不可干净撤销。

### 6.3 部门调动

人员管理 →「**编辑**」→ 改「部门」→ 保存。

- 只能选**同一法人主体下**的部门，跨主体调动界面做不了；改动**立即生效、没有生效日期**。
- **没有调动记录/异动历史**，改完即覆盖。
- 历史工资表的部门**不变**（存的是当时快照）；工龄不受影响；调动与调薪不联动。

## 7. 个税核对

左侧「**个税核对**」→ 选年度（**默认上一年，请改成本年**）→ 可选部门/员工 →「查询」。

| 列 | 含义 / 怎么核对 |
|---|---|
| 计薪月数 | 本年度已计薪月份数；累计减除 = 5,000 × 此数 |
| 累计收入 / 累计减除 | 与逐月工资表相加、月份数核对 |
| 累计社保 / 累计公积金 | 与参保信息、编制台扣款列核对 |
| 累计专项 | 与录入的月额 × 月数核对 |
| 应纳税所得额 | 收入 − 减除 − 社保 − 公积金 − 专项（负数按 0） |
| 累计已预扣 / 最近一期个税 | 最近一期与编制台「个人所得税（扣）」核对 |
| 税负率 | 累计已预扣 ÷ 累计收入，**不能加总**（合计行 —） |

异常判断：累计减除对不上 → 月份口径问题（年中入职从入职月起算）；社保/公积金为 0 → 没配参保；税额下半年跳档 → 累计预扣的正常现象；最近一期与编制台不一致 → 可能解锁未重算，找复核员/开发。

两个边界：只统计**已锁定/已归档**期间（顶部会提示未锁定月份）；个税上线前锁定的历史期间**没有累计台账**，年中上线需实施人员补录期初累计。


## 8. 红线与常见报错

| 提示 | 原因 | 怎么办 |
|---|---|---|
| 期间已锁定，禁止修改 | 已锁定 | 让复核员解锁 |
| 锁定人不能是本期间的编制人 | 自己锁自己编的 | 换复核员 |
| 上次生成有 N 人失败，请先处理再锁定 | 有失败员工 | 看失败明细，处理后重新生成 |
| 期间正在生成，请等待完成后锁定 | 生成未完成 | 等 SUCCESS |
| 预校验存在 N 行失败，禁止提交 | 文件有错 | 下载错误报告，改完重传 |
| 该工号在本期间没有核算记录 | 导入只改已有记录 | 确认已生成且未被跳过 |
| 该工资项已停用 | 科目被停用 | 找管理员 |
| 无权限执行该操作 | 缺权限 | 找管理员/复核员 |
| 该城市编码不存在或未配置险种参数 | 参保城市非 BJ/SH/SZ | 改选内置城市 |
