# 部门主管操作手册

> **适用账号**：由管理员开通的「部门主管」账号（角色 `DEPT_MANAGER`）
> **这本手册解决什么**：你能在系统里查什么、查到的是哪个口径、以及哪些事系统现在做不到。
> **一句话定位**：你是**只读的团队成本观察者**——能看本部门及下级，不能改、不能导出、看不到别的部门。

---

## 0. 一页速查：你能做什么 / 不能做什么

| ✅ 你能看到 | ❌ 你看不到 / 做不到 |
|---|---|
| 本部门及下级部门的人员名单 | 其他部门的人员和工资 |
| 本部门每月的工资人数、应发合计、实发合计 | 全公司合计（你看到的合计只含你的范围） |
| 编制台里本部门每个人的工资明细（只读） | 修改任何工资数据 |
| 月度报表（本部门一行） | 导出任何报表/工资表（按钮不显示） |
| 年度报表（按人/按部门，限本部门） | 工资项字典维护、系统管理 |
| 个税核对（本部门） | 完整证件号/手机号（只显示掩码） |
| 下属的「薪酬档案」（基本工资、调薪历史） | 团队趋势、人均成本、编制对比等分析（二期） |

**权限边界是服务端强制的**：即使你手动改网址，也拿不到其他部门的数据。

---

## 1. 登录后你会看到什么

1. 打开系统地址，用管理员给你的账号登录。
2. 默认落在「**工资期间**」页。
3. 左侧菜单有：人员管理 / 工资项 / 工资期间 / 月度报表 / 年度报表 / 个税核对。
   - 没有「系统管理」——这是对的。
4. 右上角灰色小标签显示 `DEPT_SUB`，这是系统内部的数据范围代码（"本部门及下级"），不是错误，也不代表其他含义。

> 页面顶部没有"当前部门：XX"的标识。**你看到的任何合计都只是你管辖范围的合计**，不要当成公司数据向上汇报。

---

## 2. 你能看到的页面

> 左侧还有一个「工资项」菜单，那是全公司的工资科目字典（只读）。它不针对你的部门，日常可以忽略。

### 2.1 人员管理

- 只显示**你本部门及下级部门**的员工（在职、离职都在，除非你筛选）。
- 可按「姓名或工号」「部门」「员工类型」「在职状态」筛选，点「查询」。
- 列表列：工号、姓名、性别、部门、员工类型、职级、岗位、入职日期、工龄、证件号（掩码）、手机号（掩码）、状态。
- 没有「新增人员」「批量导入」「编辑」按钮——你不能改人事数据。
- 行内「**薪酬档案**」可以打开，看到该员工的：
  - 当前生效薪酬（基本工资、固定津贴、生效日期、调整原因）；
  - 调薪历史时间线（每段的起止、金额、原因、是否有效）。
  - 另有「参保信息」「专项附加扣除」两个标签，同样只读。

> 说明：**当前版本允许主管查看下属的个人薪酬明细**。如果你的公司政策不允许，请向系统管理员/HR 负责人提出，由他们决定是否调整角色（系统目前没有"只看部门汇总、不看个人"的权限粒度）。

### 2.2 工资期间

- 列出你范围内每个月的期间：工资年月、状态（草稿/编制中/已锁定/已归档）、人数、应发合计、实发合计、计薪天数。
- **注意口径**：
  - 人数 = 该月你范围内**有工资记录**的人数，不等于在职人数；
  - 应发 = 所有增项之和；实发 = 应发 − 扣款（扣款已含社保个人、公积金个人、个人所得税）。
- 你能看到**「编制中」的期间**。这类数据 HR 还可能修改，**金额不是最终数**；对外引用请以「已锁定」为准。
- 没有「新建期间」「生成」「导入」「锁定」「解锁」按钮——这些不是你的职责。
- 行内「**编制台**」可以进入（见 2.3）。

### 2.3 编制台（只读）

- 顶部黄色提示「当前账号没有 payroll:record:edit 权限，编制台为只读」。
- 可以按部门、员工类型、职级、工号/姓名筛选；可以看每个人的：
  - 工号、姓名、部门、类型、职级、工龄；
  - 各工资项金额（基本工资、岗位津贴、工龄工资、绩效奖金、加班工资、其他奖金、考勤扣款、其他扣款、社保个人、公积金个人、个人所得税等）；
  - 底部应发合计 / 扣款合计 / 实发合计。
- **不能双击编辑、不能保存、不能导出**（导出按钮不显示）。
- 如果页面状态是「已锁定」，数据即为最终数；「编制中」则可能继续变化。

### 2.4 月度报表

1. 选「工资年月」（默认上个月）→ 可选法人主体/部门 → 「查询」。
2. 你只会看到**本部门一行**（如"北京研发中心 225 人 / 应发 / 扣款 / 实发"）。
3. 页面提示「仅统计已锁定/已归档期间」：**没锁定的月份查出来是空，这是正常的**，不是没发工资。
4. 有「导出 xlsx」按钮吗？**没有**（无导出权限）。

### 2.5 年度报表

1. 选年份（默认今年）→ 选「按人」或「按部门」→ 查询。
2. 按人：本部门每个人的年度应发/扣款/实发、月份数；按部门：本部门一行、去重人数。
3. 只统计已锁定月份；页面会提示哪些月份"已有工资数据但未锁定，未计入"。
4. 同样**没有导出按钮**。

### 2.6 个税核对

1. 选年度（**默认上一年**，注意改成本年）→ 可选部门/员工 → 查询。
2. 可看本部门每个人的：计薪月数、累计收入、累计减除、累计社保/公积金/专项、应纳税所得额、累计已预扣、最近一期个税、税负率。
3. 税负率 = 累计已预扣 ÷ 累计收入，**不能相加**（合计行显示 —）。
4. 只统计已锁定月份，没有导出按钮。

## 3. 常见问题（口径类）

**Q1：为什么我看到的人数和 HR 说的不一样？**
三种常见原因：① 你只看本部门及下级；② 你数的是"有工资记录的人"，HR 可能数的是"在职人数"；③ 有人没配薪酬档案/当月未入职，被跳过。

**Q2：为什么这个月金额和上周看的不一样？**
如果状态是「编制中」，HR 还在改（导入绩效、手工调整、重新生成），金额会变。**已锁定**的期间不会变。

**Q3：为什么月度报表查出来是空的？**
该月还没锁定。报表只统计已锁定/已归档期间；等复核员锁定后再查。

**Q4：为什么我没有导出按钮？**
你的角色没有导出权限（导出是高风险操作，单独授权）。需要数据时请找 HR/薪酬专员导出，或让管理员评估是否授权。

**Q5：部门下拉里为什么只有本部门及下级？**
系统按你的数据范围过滤了部门选项，选不到别的部门是正常的。

**Q6：页面上的"锁定人不能是本期编制人""解锁必须填写原因"跟我有关吗？**
无关。这些是给薪酬专员/复核员的提示，你既不能锁也不能解锁。

**Q7：为什么人员列表里的证件号/手机号是星号？**
敏感字段默认脱敏；你没有"查看敏感字段"权限。需要联系员工本人或走 HR 流程。

## 4. 当前版本没有、但主管通常想要的功能（二期）

以下功能**现在不支持**，不要在汇报中假设它们存在：

| 想要的能力 | 现状 |
|---|---|
| 团队薪酬总额趋势（近 6/12 个月） | 只能逐月查「工资期间」或「月度报表」，没有趋势图 |
| 人均成本 | 没有此指标；只能自己用"应发合计 ÷ 人数"手算 |
| 编制 vs 实际 | 系统里**没有编制/headcount 字段**，做不了 |
| 本月 vs 上月、同比/环比 | 报表一次只查一个期间，没有对比视图 |
| 离职率/人员流动分析 | 只能按"在职状态=离职"筛人，没有比率和趋势 |
| 导出团队报表 | 无导出权限，按钮不显示 |
| 按职级/岗位/用工类型的薪酬结构 | 报表只有"按人""按部门"两种维度 |
| 预算/成本预警 | 无预算字段、无预警 |
| 团队概览仪表盘 | 无此页面，落地页是工资期间台账 |
| 本期异动汇总（新入职/调薪/离职） | 只能逐人看人员列表和薪酬档案 |

这些已列入二期需求（团队趋势、人均成本、编制对比、环比、离职率、团队报表导出、按职级聚合、预算预警）。在此之前，需要分析数据请让 HR 导出后在 Excel 里做。

## 5. 使用纪律

1. **只用于本职管理**：下属工资属于敏感信息，不要截图转发、不要发到群里。
2. **引用数据先看状态**：对外汇报只用「已锁定」期间的数；「编制中」的数可能变。
3. **不要尝试绕过界面**：直接改网址、调接口都会被服务端按数据范围拦截，并可能留下异常记录。
4. **发现数据明显异常**（如某人工资为 0、部门挂错）：不要自己改（也改不了），把工号和时间点发给 HR 专员核查。
5. **账号只给本人用**：需要多人查看时，请管理员分别开号，不要共用。
